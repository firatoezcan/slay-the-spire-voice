# Voice Director 0.5.1

Speech setup is automatic.

The host companion downloads Parakeet on first launch, shows progress in the dashboard, and offers Retry speech setup if a download fails. It verifies every model file and keeps its own local copy for later runs. An existing matching model is reused automatically.

Oh My Pi and manual model installation are no longer required. The first download is about 670 MB. Transcription runs locally after setup.

## Install or update

Download **VoiceDirector-0.5.1.zip** from the assets below. Everyone in the party should use the same mod version with Slay the Spire 2 v0.107.1.

- [Host setup](https://github.com/firatoezcan/slay-the-spire-voice/blob/v0.5.1/docs/host-install.md): update the checkout and run `bun run mod:install` with the game closed, then launch through Steam. The host installer targets macOS ARM64.
- [Player instructions](https://github.com/firatoezcan/slay-the-spire-voice/blob/v0.5.1/docs/player-install.md): friends install the mod ZIP. Speech model setup runs on the host.
- [Model source and setup details](https://github.com/firatoezcan/slay-the-spire-voice/blob/v0.5.1/docs/speech-setup.md).

Living Deck, editable prompts, and the existing card generation flow are included. Multiplayer delivery has local contract and simulated receiver checks; a live session with two separate game clients remains untested.
