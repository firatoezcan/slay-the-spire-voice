# Voice Director 0.5.0

An early playable build for Slay the Spire 2 v0.107.1.

## Install

Download **VoiceDirector-0.5.0.zip** from the assets below. Extract its `VoiceDirector` folder into the game's `mods` directory while the game is closed, then launch through Steam. All players must use the same game and mod version.

- [Player installation](https://github.com/firatoezcan/slay-the-spire-voice/blob/v0.5.0/docs/player-install.md): friends need the game and the mod files.
- [Host setup](https://github.com/firatoezcan/slay-the-spire-voice/blob/v0.5.0/docs/host-install.md): the host runs Bun, Codex, and local Parakeet transcription. The current host installer targets macOS ARM64.

## In this release

- Living Deck is the default. Approved, prepared replacements apply on their next eligible draw, within the configured turn limits and cooldown. Original cards stay playable during generation.
- Wildcards retain one transformation after acquisition. I'm feeling lucky asks for a useful card that can take the deck in a new direction.
- The dashboard exposes six editable prompts with individual saving, defaults, and discard.
- Luna classifies conversation; Astra chooses, designs, reviews, and illustrates the cards. Decisions appear beside their transcript.
- Each player can enable ambient microphone input in the game's Sound settings. The host transcribes audio locally; recent conversation is sent to Codex.
- Generated card definitions, descriptions, portraits, and host settings travel through the game connection.
- Card protection and the additional chance roll on draw have been removed.

## Checked and remaining limits

The mod was played on macOS ARM64, including transformations on actual draws, card effects, rewards, saved cards, and artwork. Prompt saving and reset were checked in the dashboard. Builds, API validation, delivery contracts, and simulated receiving peers passed.

A live session with two separate game clients has not been tested. Multiplayer play, reconnect during combat, and simultaneous remote choices still need that validation.

The ZIP contains the mod, managed dependencies, and installation instructions. Host credentials, recordings, transcripts, generated artwork, saves, and speech models are stored separately.
